팀 실시간 공유 연결 설정

사내 공용 웹페이지 배포 방법 (2단계)

  1. 이 index.html 파일을 무료 정적 호스팅(Netlify Drop, Vercel 등) 또는 사내 웹 서버에 업로드합니다.
  2. 여러 명이 동시에 데이터를 실시간 공유하려면 무료 데이터베이스 설정(JSON)을 아래에 입력한 뒤 팀원 공유 링크 복사를 눌러 배포된 주소를 전달하세요.
